# Contributing

Thanks for helping! The short version:

1. Fork, branch, make your change.
2. `go vet ./... && go test -race ./...`
3. Open a pull request and fill in the checklist.

How the code is organised, how to run it against a fake Discord, and how releases work are in
[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

Found a bug? Run `ytm-beacon doctor` and attach its output to your issue.
